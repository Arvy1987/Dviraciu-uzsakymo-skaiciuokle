# Dviračių užsakymo skaičiuoklė

C++ programa nuskaito prekes iš `uzsakymas.txt`, apskaičiuoja nuolaidas
ir parodo mokėtinas sumas pagal prekių kategorijas.

## Kaip paleisti

1. Atidaryk projektą CLion.
2. Patikrink, ar `uzsakymas.txt` yra programos darbo aplanke.
3. Paleisk programą. Meniu pasirink `1` ataskaitai peržiūrėti,
   `2` jai išsaugoti į `ataskaita.txt`, `3` prekėms pagal kategoriją
   peržiūrėti arba `0` programai uždaryti.

Kai prekės kiekis yra 10 ar daugiau, jos eilutės sumai taikoma 10 % nuolaida.
